# 모아

휴대폰에 흩어진 파일과 날짜별 할 일을 한 화면에서 정리하는 개인용 웹앱입니다.

사진, 동영상, 문서 등의 파일을 추가하면 형식에 따라 자동으로 분류되며, 원하는 날짜를 선택해 할 일을 등록하고 완료 상태를 관리할 수 있습니다. 스카이 블루를 중심으로 한 간결한 화면과 Pretendard 서체를 사용했으며, 이모지와 그라디언트는 사용하지 않았습니다.

## 주요 기능

### 파일 정리

- 여러 파일을 한 번에 추가
- 사진, 동영상, 문서 및 기타 파일 자동 분류
- 파일명 검색
- 최근 추가순, 이름순, 용량순 정렬
- 격자 보기와 목록 보기 전환
- 이미지 미리보기
- 파일 열기 및 다운로드
- 정리함에서 파일 삭제
- 파일 개수와 사용 용량 요약

### 날짜별 할 일

- 날짜를 선택해 할 일 등록
- 선택한 날짜를 중심으로 7일 일정 확인
- 할 일 완료 및 완료 취소
- 할 일 삭제
- 날짜별 완료 개수 표시
- 오늘 남은 할 일 개수 표시

### 사용자 경험

- 데스크톱과 모바일에 대응하는 반응형 레이아웃
- 키보드로 사용할 수 있는 주요 컨트롤
- 빈 목록, 저장 성공, 오류 상태 안내
- 새로고침 후에도 파일과 할 일 유지

## 사용 방법

### 배포된 서비스

[모아 서비스 열기](https://moa-file-planner.topeghcv.chatgpt.site)

### 로컬에서 실행하기

별도 설치나 빌드 과정 없이 정적 웹 서버로 실행할 수 있습니다.

```bash
python3 -m http.server 4173 --directory dist
```

브라우저에서 `http://localhost:4173`을 열면 됩니다.

> `index.html` 파일을 직접 여는 방식보다 로컬 웹 서버 사용을 권장합니다. 브라우저 저장소와 파일 기능이 더 안정적으로 동작합니다.

## 프로젝트 구조

```text
.

    └── app.js         # 파일 관리, 검색, 정렬, 할 일 기능
```

## 기술 구성

- HTML5
- CSS3
- Vanilla JavaScript
- IndexedDB
- Pretendard Webfont

프레임워크나 별도 UI 라이브러리 없이 HTML, CSS, JavaScript만으로 제작했습니다.

## 데이터 저장 방식

추가한 파일과 할 일은 서버가 아닌 사용 중인 브라우저의 IndexedDB에 저장됩니다.

- 파일 내용과 할 일은 외부 서버로 전송하지 않습니다.
- 같은 기기에서도 다른 브라우저에서는 데이터가 공유되지 않습니다.
- 브라우저 사이트 데이터나 캐시를 삭제하면 저장된 내용도 사라질 수 있습니다.
- 브라우저의 저장 공간 제한에 따라 큰 파일이나 많은 파일은 저장되지 않을 수 있습니다.

## 브라우저 제약

웹 브라우저의 보안 정책상 앱이 휴대폰 전체 파일을 자동으로 검색할 수는 없습니다. 사용자가 **파일 추가** 버튼을 눌러 정리할 파일을 직접 선택해야 합니다.

또한 일부 파일 형식은 브라우저에서 바로 열리지 않고 다운로드될 수 있으며, 실제 동작은 기기와 브라우저 설정에 따라 달라질 수 있습니다.

## 지원 환경

최신 버전의 다음 브라우저 사용을 권장합니다.

- Chrome
- Safari
- Edge
- Samsung Internet

IndexedDB와 File API를 지원하는 모바일 및 데스크톱 브라우저에서 사용할 수 있습니다.
